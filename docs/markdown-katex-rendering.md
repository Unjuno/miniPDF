# KaTeX 数式レンダリング

miniPDF の Markdown プレビューは、`$...$` のインライン数式と `$$...$$` のブロック数式を KaTeX でレンダリングし、PNG として PDF に埋め込みます。

## 使い方

1. Markdown 内で通常どおり `$...$` または `$$...$$` を書く。
2. プレビューを更新する。
3. PDF 保存時も同じ数式が KaTeX で画像化される。

## 対応範囲

- インライン数式: `$E = mc^2$`
- ブロック数式: `$$ ... $$`
- 基本的な分数、和、積分、行列、cases などの KaTeX 記法

## 制約

- 数式はベクターのままではなく、PNG にラスタライズして埋め込む。
- 実行には `node` と `puppeteer` と `katex` が必要。
- KaTeX で解釈できない TeX は、最終的に簡易フォールバックに落ちる場合がある。
- 出力は見た目優先で、数式テキストの選択やコピーを前提にしていない。
