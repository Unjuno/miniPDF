# アーカイブ

このディレクトリには、**同一トピック（実装上のリスク・問題点）の過去スナップショット**を置いています。

## 正本（常に先に読む）

プロジェクト直下の [`../CURRENT_ISSUES_SUMMARY.md`](../CURRENT_ISSUES_SUMMARY.md) を正とします。新しい発見や状態更新は、可能な限りそちらに反映してください。

## このフォルダのファイル

| ファイル | 備考 |
|----------|------|
| `POTENTIAL_ISSUES.md` | 初期の問題リスト |
| `POTENTIAL_ISSUES_ANALYSIS.md` | 詳細分析（旧） |
| `LATEST_ISSUES_ANALYSIS.md` | 2024-12-22 時点のスナップショット |
| `FINAL_ISSUES_ANALYSIS.md` | 同上系の包括メモ（旧） |

相互参照リンクは `archive/` 内の相対パスのまま動作します。`docs/` ルートから参照する場合は `./archive/ファイル名.md` を使ってください。
