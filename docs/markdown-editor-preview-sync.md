# Markdown エディタとプレビューの位置同期

miniPDF では、Markdown エディタのカーソル位置をもとに、プレビュー PDF のページ位置をおおまかに追従させます。

## 使い方

1. Markdown エディタに入力する。
2. カーソル位置に応じて、プレビューが近いページへ移動する。
3. プレビュー側をスクロールすると、現在ページも更新される。

## 制約

- 同期は厳密な行単位ではなく、Markdown 全体の行数と PDF のページ数から推定する。
- レイアウトの密度が高い文書では、実際の要素位置と多少ずれることがある。
- 目的は「書いている場所と見ている場所を近づける」ことで、完全一致ではない。
