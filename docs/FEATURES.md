## 概要

**miniPDF** は、**Markdown を書きながら PDF をライブプレビュー**し、必要なら **PDF として保存**する軽量デスクトップアプリです。印刷に近い見た目を右ペインで確認します。

### 解決する問題

- Markdown + Mermaid を PDF にしたときの**見た目の確認**を、アプリ内で繰り返し行える
- 左でソース、右で生成結果を並べて**編集と確認の往復**を短くする

### 特徴

- **軽量** - 起動が速い想定のスタック（Tauri + React + PDF.js）
- **プレビュー専用** - PDF 上でのブロック移動・ページ追加などのレイアウト編集 UI は持たない
- **OSS**

## ファイル操作

### Markdown ファイルの読み込み

1. 「MDを開く」または `Ctrl+O`
2. ファイル選択で `.md` 等を指定

Tauri 外（ブラウザのみ）ではファイルダイアログは使えません。

### Markdown ファイルの保存

1. 「MD保存」または `Ctrl+S`
2. 保存先を指定

### PDF ファイルの保存

プレビューに表示している内容を、別名で PDF 保存します（「PDF保存」）。
Markdown プレビュー由来の一時 PDF は、そのまま保存するため Mermaid 図などの描画結果を落としません。
読み込んだ元 PDF は、画像データが空のままの再生成を避けるため、条件に応じて元ファイルをそのまま保存します。
通常の PDF 読み込みでは画像バイトも保持するため、編集後の再保存でも画像欠落を起こしにくくなっています。

## Markdown とプレビュー

- 左ペインのテキストエリアに Markdown を入力します。
- **段落内の単一改行**はプレビュー PDF でも改行として出ます（末尾に半角スペースを2つ付ける CommonMark の「改行」記法に加え、通常の改行もそのまま反映）。**空行**は余白としてレイアウトに反映され、**区切り線**（`---` など）と **ネストした箇条書き**も描画します。
- 入力はデバウンスされ、バックエンドで一時 PDF が生成され、右ペインに読み込まれます。
- Mermaid ブロックは `mmdc` が使える環境では画像化され、使えない場合はコードブロック表示にフォールバックします。`mmdc` の探索順は **環境変数 `MINIPDF_MERMAID_CLI`（絶対パス）→ リポジトリ直下の `node_modules/.bin/mmdc`（`npm install` 後）→ 実行ファイル同階の `mmdc` / `bin/mmdc` → PATH の `mmdc`**（Windows / macOS / Linux 共通）です。

## PDF プレビュー表示

- **PDF.js** でページを描画します（印刷レイアウトの確認用）。
- **オーバーレイ**（テキスト枠・画像枠の点線、ドラッグでの移動・リサイズ）は表示しません。
- プレビュー下部の **スクロール矢印**（上下左右）はそのまま使えます。
- 上部で **連続表示** と **1 ページ表示** を切り替えられます。

## キーボードショートカット

| ショートカット | 機能 |
|--------------|------|
| `Ctrl+O` | Markdown を開く（Tauri 時） |
| `Ctrl+S` | Markdown を保存（Tauri 時） |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | ズームイン・アウト・リセット（PDF 表示中） |

## 操作方法

### 基本的な流れ

1. Markdown を開くか、左エディタに入力する。
2. 右のプレビューで PDF が更新されるのを待つ。
3. 必要ならズーム・ページ送り・表示モードで確認する。
4. 「MD保存」「PDF保存」で成果物を書き出す。

### エラー

画面上部のエラー表示で通知されます。プレビュー失敗時はトーストやステータス文言も確認してください。

## レイアウト編集について（非対応）

次のような **PDF 上での直接編集**や **ページ一覧 UI** は、現行製品では提供しません（旧実装の `PageEditor` および `PDFViewer` 内の編集ツールバーは撤去済み）。

- ページの追加・削除・並べ替え UI
- テキストブロック・画像のクリック選択・ドラッグ移動・インライン編集
- 改ページラインのドラッグ調整ツール

レイアウトの詰めは **Markdown 側の見出し・空行（空行は余白として反映）・Mermaid サイズ**や、将来の **生成ロジック（Rust）の改善**で行う想定です。印刷で空白ページや図切れが出る場合は [docs/bugs/print-preview-quality-followup.md](./bugs/print-preview-quality-followup.md) を参照し、再現手順を追ってください。
