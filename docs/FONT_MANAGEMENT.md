# フォント管理機能

## 概要

miniPDFでは、様々なフォントを使用してPDFを生成できるフォント管理機能を実装しています。これにより、日本語などのマルチバイト文字を正しく表示できます。

## 実装状況

### 完了した機能

1. **フォント管理モジュール** (`src-tauri/src/utils/font_manager.rs`)
   - フォントレジストリの実装
   - フォントファイルの検出と登録
   - フォントの利用可能性チェック

2. **フォントディレクトリ** (`src-tauri/fonts/`)

3. **PDF生成時の統合**
   - フォント管理機能をPDF生成プロセスに統合
   - 非ASCII文字を含むテキストの検出

### 未実装の機能

2. **フォントファイルのビルド時のパッケージング**
   - フォントファイルを実行ファイルと一緒に配布する設定

## 使用方法

### フォントファイルの配置

1. フォントファイル（.ttf または .otf）を `src-tauri/fonts/` ディレクトリに配置
2. 推奨フォント：
   - `NotoSansJP-Regular.ttf` → `NotoSansJP`
   - `NotoSansJP-Bold.ttf` → `NotoSansJP-Bold`
   - `NotoSerifJP-Regular.ttf` → `NotoSerifJP`

### フォントの登録

フォントは自動的に検出され、登録されます。フォントファイルが存在する場合、以下のログが出力されます：

```
フォントを登録しました: NotoSansJP -> .../fonts/NotoSansJP-Regular.ttf
```

## 技術的な詳細

### フォントレジストリ

フォントレジストリはシングルトンパターンで実装されており、アプリケーション起動時に一度だけ初期化されます。

### フォントディレクトリの検出

フォントディレクトリは、実行ファイルのディレクトリから相対パスで検出されます：
- 実行ファイルのディレクトリ/`fonts/`
- フォールバック: `fonts/`（カレントディレクトリ）

### PDF生成時のフォント選択

1. テキストに非ASCII文字が含まれる場合：
   - 日本語フォント（`NotoSansJP`）が利用可能かチェック
   - 利用可能な場合、カスタムフォントを使用（実装予定）
   - 利用できない場合、テキストをスキップ（警告ログを出力）

2. ASCII文字のみの場合：
   - 標準フォント（Helvetica、Times-Roman、Courier）を使用
