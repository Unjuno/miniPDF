# main.tsxのグローバルエラーハンドラー追加

## 症状
- 未処理のエラーやPromise拒否が発生した場合、ユーザーに通知されない
- デバッグが困難

## 根本原因
`main.tsx`にグローバルエラーハンドラーがありませんでした。これにより、予期しないエラーや未処理のPromise拒否が発生した場合、ユーザーに通知されず、デバッグが困難でした。

## 修正内容
1. `window.addEventListener('error')`を追加して、未処理のエラーをキャッチし、ログに記録
2. `window.addEventListener('unhandledrejection')`を追加して、未処理のPromise拒否をキャッチし、ログに記録
3. `logger`をインポートして、エラーをログに記録

## 修正ファイル
- `src/main.tsx`

## 回帰防止
- グローバルエラーハンドラーにより、予期しないエラーをキャッチし、ログに記録できるようになりました
- デバッグが容易になりました
- ユーザーにエラーが通知されるようになりました（ログを通じて）
