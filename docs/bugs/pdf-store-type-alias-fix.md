# pdfStore.tsの型エイリアス修正

## 症状
- 複雑なユニオン型がインラインで使用されていた
- 同じ型定義が複数箇所で繰り返されていた

## 根本原因
リンターが推奨するベストプラクティスに従っていませんでした。複雑な型は型エイリアスとして定義することで、コードの可読性と保守性が向上します。

## 修正内容

### 型エイリアスの作成
- `Array<{ type: 'imageExtraction' | 'textExtraction' | 'unexpected'; pageNumber: number }>`を`PageProcessingError[]`型エイリアスに置き換え
- 型エイリアスをファイルの先頭で定義

### 修正箇所
- 3箇所の型定義を型エイリアスに置き換え

## 修正ファイル
- `src/stores/pdfStore.ts`

## 回帰防止
- すべてのテストが通過
- ビルドが成功
- リンターエラーが減少
- コードの可読性と保守性が向上
