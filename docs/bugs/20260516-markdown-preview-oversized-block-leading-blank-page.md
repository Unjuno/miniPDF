# Markdown プレビューで oversized block の先頭に空ページが入る問題

## 症状

Markdown プレビュー PDF に、ページ先頭が空白のまま始まるページが混ざることがあった。特に、巨大なコードブロックや長いブロックが先頭に来ると発生しやすかった。

## 根本原因

`ensure_room()` が、ページ先頭で既にページに収まらないブロックに対しても空ページを追加してから描画していた。その結果、ブロック自体は次ページに描かれる一方、元の空ページが残っていた。

## 修正

ページ先頭でブロックがページ高さを超える場合は、不要な空ページを挿入しないようにした。

## 再発防止

- `src-tauri/src/commands/markdown_preview.rs` に、巨大なコードブロックが先頭の空ページを作らないことを確認する回帰テストを追加した。
