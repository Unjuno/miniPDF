# Bug note: 引用ブロックの表示が外れることがある

## 症状
- 長い引用や、引用内にリスト・数式を含む Markdown で、引用の背景や左罫線が途中で外れて見えることがあった。
- 特に、引用内の display math が通常の1行テキストとして扱われ、引用のまとまりが崩れて見えるケースがあった。

## 根本原因
- 引用ブロックを段落単位の塊として扱っていたため、ページ分割の単位が粗すぎた。
- 引用内の display math を独立した行として保持せず、通常のテキスト行に潰していた。

## 修正
- 引用の内容を表示行単位で保持し、ページ分割も表示行ごとに行うようにした。
- 引用内の display math は別行として扱い、通常のテキスト行と分離して描画するようにした。
- HTML プレビュー側も同じ行分割ルールに合わせた。

## 再発防止
- `long_blockquote_spans_multiple_pages_in_pdf_and_html` で長文引用のページ分割を固定した。
- `blockquote_display_math_is_preserved_as_a_separate_line` で引用内 display math を別行として扱うことを固定した。
