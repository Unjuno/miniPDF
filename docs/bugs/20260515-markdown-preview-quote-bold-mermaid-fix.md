# Bug note: Markdown プレビューの引用・和文太字・Mermaid 表示崩れ

- **日付**: 2026-05-15
- **種別**: Bug
- **ステータス**: 修正済み

## 症状

Markdown プレビューで、引用ブロックの本文が背景と詰まり気味になる、和文の太字が弱く見える、Mermaid 図が空白になることがあった。

## 原因

- 引用ブロックが通常段落と同じ描画基盤を使っていて、上下余白が不足していた。
- 和文太字は同梱ボールドフォントが無い場合に通常体へ落ちており、見た目で太字に見えにくかった。
- Mermaid CLI の探索が開発実行時のディレクトリ構成を取りこぼす場合があった。

## 修正

- 引用ブロックを専用描画にして、背景・左バー・本文の開始位置を分離した。
- 和文太字は、ボールドフォントが無い場合に 3 回重ね描きする合成太字へ切り替えた。
- Mermaid は `MINIPDF_MERMAID_CLI`、ワークスペース直下の `node_modules/.bin`、`cwd` 祖先を順に探索し、画像化できない場合はフォールバック表示へ落とす。

## 再発防止

- `cargo test markdown_preview -- --nocapture`
- `cargo test -- --nocapture`
- Mermaid CLI 探索の unit test と、最小 Mermaid 図のレンダリング test を追加した。
