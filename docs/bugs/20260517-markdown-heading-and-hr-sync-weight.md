# Markdown heading and horizontal rule sync weight

## Symptom
- `#` 見出しや `---` の水平線を挟んでも、プレビューのページ位置がほとんど動かず、空行と同じような扱いに見えた。
- その結果、見出し直前に補助行を入れても、カーソル同期のページ推定が十分に変化しなかった。

## Root Cause
- ページ推定ロジックが、見出しや水平線の見た目の高さを十分に強く反映していなかった。
- 特に水平線は、空行より少し重い程度の扱いで、実際のレイアウト上の区切りとしては弱すぎた。

## Fix
- 見出しレベルごとに異なる重みを付け、`#` が強いページ区切りとして効くようにした。
- `---` / `***` / `___` の水平線も、空行とは別のまとまりとして扱うようにした。
- 見出しと水平線が空行より強くページ推定へ反映される unit test を追加した。

## Regression Prevention
- `src/utils/markdownPositionSync.test.ts` の structural line tests を追加・更新した。
- 実際の見た目と同期がずれたら、水平線と見出しの重みをこのテストで再調整する。
