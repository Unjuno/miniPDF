# Markdown Visual Layout Compactness

## Symptom
- 日本語の斜体がページ端まで流れて見えることがあった
- blockquote の箱が本文より広く、ネストの見え方も崩れていた
- 番号付きリストの prefix が強調され、見た目が不自然だった
- 短いコードブロックまでページ途中で分割されていた

## Root Cause
- 日本語の斜体を文字ごとの横ずらしで擬似表現しており、累積オフセットが大きくなっていた
- blockquote を複数の独立した箱に分解して描画していたため、ネストや余白が不自然になっていた
- ordered list / bullet の prefix を太字で描画していた
- コードブロックを常にチャンク分割していたため、1 ページに収まる場合でも不必要に分断されていた

## Fix
- 擬似イタリックの横ずらし量を抑え、段落全体がずれすぎないようにした
- blockquote を 1 つのまとまりとして描画し、ネストした引用は prefix で表現するようにした
- list prefix を通常スタイルへ戻した
- 1 ページに収まるコードブロックは分割せず、そのまま描画するようにした

## Regression Prevention
- blockquote が 1 ブロックにまとまることを unit test 化
- 短いコードブロックが 1 ページ描画を優先することを unit test 化
- Markdown 視覚確認用 fixture を使って、今後も同じレイアウト崩れを目視・テスト両方で確認する
