# Bug Note: 数式のベースラインが少し低く見える問題

- **日付**: 2026-05-19
- **種別**: Bug
- **ステータス**: 修正済み
- **対象**: `src-tauri/src/commands/markdown_preview.rs`

## 症状

- インライン数式が本文より少し下に寄って見えることがあった。
- display 数式も、配置によっては少し下に沈んで見えることがあった。

## 修正

- KaTeX のレンダリング結果から、インライン数式のベースライン位置を実測するようにした。
- そのベースラインを使って、画像の縦位置を固定値ではなく実測値で合わせるようにした。
- さらに、本文との見た目を合わせるために、インライン数式の追加オフセットを -4px 相当にした。
- 数式を含む行には追加の行高を確保して、blockquote 内で潰れにくくした。
- 透明余白トリムと合わせて、数式の見た目を本文と揃えやすくした。

## 再発防止

- 数式描画のベースライン調整をする場合は、visual check の inline / display / blockquote 数式を確認する。
- KaTeX の画像余白トリムと、ベースライン計測を維持する。
