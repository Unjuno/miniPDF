# 日本語の太字斜体が細く見える問題

## 症状

Markdown の `***太字斜体***` に日本語が含まれると、斜体には見えても太字が十分に乗らないことがあった。

## 根本原因

日本語の斜体描画が途中で通常フォント扱いに戻り、`style.bold` による太字合成が弱い経路へ落ちていた。

## 修正

1. 日本語の斜体は vector fallback で描くように統一した。
2. 斜体経路でも `style.bold` を見て太字合成を有効にした。
3. 太字合成の描画オフセットを調整し、`***太字斜体***` が太字として認識しやすいようにした。

## 再発防止

1. 日本語の斜体と太字斜体を同じサンプルで PDF 生成して確認する。
2. `italic` 関連テストで、日本語斜体が body フォント経路に入ることを確認する。
