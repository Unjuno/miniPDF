# Markdown blockquote page break handling

## Symptom
- 長い引用ブロックがページ末で途中切れになり、背景や左罫線が次ページへ自然に続かず、途中でデザインが切れて見えた。
- HTML プレビューでは、引用の高さ見積もりが短すぎて、1 ページ分の枠に押し込まれたまま切れていた。

## Root Cause
- PDF 側の `blockquote` は1ブロックとして描画されており、長い引用をページ境界で分割する処理がなかった。
- HTML 側は引用を固定 `48pt` と見積もっていたため、実際より小さく扱われてページ分割が遅れた。

## Fix
- 引用を行単位でページに収まるサイズへ分割し、ページをまたぐときは各ページ片で背景と左罫線を再描画するようにした。
- HTML 側も引用チャンクをページ単位で分割し、固定値ではなく実際の行数に応じて高さを積み上げるようにした。
- 引用の CSS 余白と行間を、PDF 側の見た目に近づけた。

## Regression Prevention
- 長文引用が PDF と HTML の両方で複数ページに分割される unit test を追加した。
- 既存の visual check fixture でも引用の見え方を継続確認する。
