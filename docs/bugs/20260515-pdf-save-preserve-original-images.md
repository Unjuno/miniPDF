# Bug note: PDF 保存時に元画像が欠けて Acrobat 警告が出る

- **日付**: 2026-05-15
- **種別**: Bug
- **ステータス**: 修正済み

## 症状

読み込んだ PDF をそのまま保存したときに、画像が欠けたり、Acrobat で「画像のデータに不足があります」と表示されることがあった。

## 原因

PDF を `pdfStructure` から再生成していたが、読み込み時に画像本体を保持しておらず、画像データが空のまま保存される経路があった。

## 修正

- Markdown プレビュー由来の PDF は、そのままのバイト列を保存する。
- 読み込み済み PDF で画像データが空のときは、再生成ではなく元ファイルのバイト列を保存する。

## 再発防止

- `savePdf` が `previewPdfPath` または元ファイルを再利用できるときは `generate_pdf` を呼ばないことを `pdfStore.test.ts` で検証する。
- 画像データが未復元のまま再生成する経路を残さない。
