# Bug Note: 印刷結果とプレビューの差（追跡用）

## ステータス

Open（調査・修正は別イテレーション）

## 症状（ユーザー報告の例）

- Markdown + Mermaid を PDF として印刷すると、**空ページ**が出る
- **図が途中で切れる**、**不自然な位置で本文が切れる**

## 根因（仮説）

- UI のレイアウト編集の有無とは独立し、**Rust 側の Markdown→PDF 生成**（例: `src-tauri/src/commands/markdown_preview.rs`）のページ分割・画像高さ・余白が原因になり得る
- ブラウザ／OS の印刷パイプラインと PDF.js プレビューの差

## 現状の製品方針

- メイン画面は **プレビュー専用**（`PDFViewer` の `previewOnly`）。キャンバス上の編集 UI は出さない

## 次の検証（推奨）

1. 同じ Markdown で **アプリ内プレビュー PDF** と **印刷出力**を並べて比較する
2. 再現するなら、最小 Markdown（Mermaid あり/なし）を `docs/bugs/` に手順付きで追記する
3. `markdown_preview.rs` のページ高さ・Mermaid 画像スケール・改ページ境界をログまたは一時ファイルで確認する

## 再発防止

- 生成パイプライン用の **回帰テスト用フィクスチャ**（短い .md + 期待ページ数の目安）を追加することを検討
