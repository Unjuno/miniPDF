# index.htmlのdescriptionメタタグ追加

## 症状
- `index.html`に`description`メタタグがない
- SEOやアクセシビリティの向上の機会を逃している

## 根本原因
`index.html`に`description`メタタグがありませんでした。これはSEOやアクセシビリティの向上に役立ちます。

## 修正内容
`index.html`の`<head>`セクションに`description`メタタグを追加しました。

## 修正ファイル
- `index.html`

## 回帰防止
- SEOの向上
- アクセシビリティの向上
- ブラウザのブックマークやシェア時の説明文として使用される
