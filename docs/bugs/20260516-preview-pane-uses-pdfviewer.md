# Bug Note: プレビューと保存PDFの見え方がずれていた

- **日付**: 2026-05-16
- **種別**: Bug
- **ステータス**: 修正済み
- **対象**: `src/App.tsx`

## 症状

- 右ペインのプレビューが、保存した PDF と微妙にずれて見える。
- Mermaid や改ページ境界、画像の位置が、表示上の HTML プレビューと実際の PDF で一致しない。

## 根因

- アプリの右ペインが、実際の PDF を描画するのではなく、Rust 側で生成した HTML の近似プレビューを描いていた。
- そのため、ページ分割や画像サイズ、余白の違いがそのまま表示差になっていた。

## 修正

- 右ペインを `HtmlPreview` から `PDFViewer` に切り替えた。
- これにより、右ペインは実際に生成された PDF を PDF.js で描画するようになった。
- 保存時の PDF と、画面上で確認するプレビューが同じバイナリを参照するようになった。

## 再発防止

- 右ペインは近似 HTML ではなく、PDF 本体を描画することを維持する。
- Mermaid、改ページ、画像位置の確認は、表示と保存の両方で同じ PDF を使って検証する。
