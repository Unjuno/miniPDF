# Bug Note: 引用ブロックが狭すぎて本文がはみ出す問題

- **日付**: 2026-05-18
- **種別**: Bug
- **ステータス**: 修正済み
- **対象**: `src-tauri/src/commands/markdown_preview.rs`

## 症状

- 引用ブロックの背景幅が本文の長さ依存で狭くなり、長めの文章が枠からはみ出して見えることがあった。
- HTML プレビュー側でも引用内の長い文やコードが折り返されず、横にはみ出すことがあった。
- 見た目が本文の重みと合わず、引用としてのまとまりが弱かった。

## 修正

- PDF 側の引用ブロック幅を、本文長さではなくページの有効幅に揃えた。
- 引用内テキストの折り返し幅を引用ブロック幅に寄せた。
- HTML 側の `blockquote` に `overflow-wrap` と `word-break` を追加し、長い文章がはみ出さないようにした。

## 再発防止

- 引用ブロックについて、長文が 1 行で固定されないことをテストで確認する。
- PDF を画像化して、引用の背景と本文が同じ幅に収まっていることを visual check で確認する。
