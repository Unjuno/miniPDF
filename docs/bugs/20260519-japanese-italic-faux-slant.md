# Bug Note: 日本語の斜体がプレビューで見えない

- 症状: 通常文の中で `*斜体*` や `***太字斜体***` を使っても、日本語部分がほぼ直立のままで、斜体として読めなかった。
- 根本原因: 日本語に対しては標準の斜体フォントが効かないため、既存の描画経路では見た目の傾きが弱すぎた。
- 修正: 日本語の斜体描画を graphics の shear transform を使うフェイク斜体に切り替え、太字との組み合わせも同じ経路で描画するようにした。
- 再発防止: 日本語グラフェムがフェイク斜体経路に入ることと、十分に視認できる shear 値を保つテストを追加した。
