# App.tsxのZustandセレクター最適化

## 症状
- `usePdfStore()`でオブジェクト分割代入を使用しており、すべての状態変更で再レンダリングが発生する可能性がある
- パフォーマンスの問題

## 根本原因
`App.tsx`で、`usePdfStore()`からオブジェクト分割代入を使用していました。これにより、ストア内の任意の状態が変更されると、コンポーネントが再レンダリングされる可能性がありました。

## 修正内容
1. オブジェクト分割代入を削除
2. 個別のセレクターを使用して、必要な状態のみを購読するように変更
3. これにより、必要な状態のみが変更された場合にのみ再レンダリングが発生する

## 修正ファイル
- `src/App.tsx`

## 回帰防止
- 個別のセレクターにより、不要な再レンダリングを防ぎました
- パフォーマンスが向上しました
- Zustandのベストプラクティスに従いました
