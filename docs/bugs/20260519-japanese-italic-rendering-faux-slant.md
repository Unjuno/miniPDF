# 日本語の斜体が見えない問題

## 症状

Markdown の `*斜体*` や `***太字斜体***` に日本語が含まれると、PDF プレビュー上で斜体に見えない、または文字が欠けて見えることがあった。

## 根本原因

1. `graphics().transform()` は text 描画には効かないため、斜体の shear が実際の文字描画に反映されていなかった。
2. 日本語向けの custom italic face を選んでいたが、そのフォントが環境によって glyph を正しく出せず、箱文字になることがあった。

## 修正

1. 日本語の斜体は custom italic face ではなく、通常の body フォントを使って描画するようにした。
2. 斜体の見た目はグラフェム単位の faux slant ではなく、body フォントをラスタライズして shear した画像として描画するようにした。
3. これにより、日本語でも文字が欠けず、PDF で斜体の見た目が出るようになった。

## 再発防止

1. 日本語斜体の回帰テストで、`face.pick()` が body フォントを使うことを確認する。
2. PDF 生成後にサンプルを画像化して、斜体 span が正常な文字として見えることを目視確認する。
3. raw PDF bytes ではなく、`load_pdf()` 経由の抽出結果で display math の回帰を確認する。
