# Bug Note: Mermaid 図の PDF 配置が左寄せ・過大表示になっていた

## 症状

Markdown プレビューでは Mermaid が画像化されるのに、PDF に起こすと図が左寄せで大きく表示され、本文との位置関係が不自然に見えることがあった。

## Root Cause

Mermaid PNG を PDF に描画するとき、画像の実寸を考慮せずページ幅いっぱいに拡大し、左端のマージンに固定していた。そのため、HTML プレビューの見え方と PDF の見え方がずれていた。

## Fix

- Mermaid 画像の描画サイズを CSS の 96dpi 相当の `0.75 pt / px` で自然サイズ寄りに換算した。
- ページ内に余白がある場合は中央配置するようにした。
- 画像の最大高さは既存の上限を維持し、ページをまたぐ不安定さは避けた。

## Regression Prevention

- 小さめの Mermaid 図が中央配置されることをユニットテストで確認する。
- 大きい Mermaid 図がページ幅・最大高さを超えずに収まることをユニットテストで確認する。
