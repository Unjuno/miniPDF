# Bug Note: 数式画像の透明余白で表示位置がずれる問題

- **日付**: 2026-05-18
- **種別**: Bug
- **ステータス**: 修正済み
- **対象**: `src-tauri/src/commands/markdown_preview.rs`

## 症状

- インライン数式が本文のベースラインから少しずれて見えることがあった。
- ブロック数式が余白込みの画像サイズで配置されるため、上下の位置が少し不自然に見えることがあった。

## 修正

- KaTeX のスクリーンショットを透明背景で取得するようにした。
- PDF に埋め込む前に、数式画像の透明余白を切り詰めるようにした。
- トリム後の実寸で配置計算を行うことで、本文と数式の縦位置を揃えやすくした。

## 再発防止

- 数式画像のトリム処理に対する単体テストを維持する。
- インライン数式と display 数式の visual check を壊さないようにする。
