# Bug note: `load_pdf` が画像バイトを落として再保存で欠落する

## 症状
読み込んだ PDF を編集して保存すると、画像や Mermaid 図が欠けたり、Acrobat で「画像のデータに不足があります」と警告されることがあった。

## 根本原因
`load_pdf` がページ内の画像を検出しても、`ImageElement.data` に実データを入れていなかった。  
そのため、`generate_pdf` が `pdfStructure` から再生成すると、画像が空データとして扱われて欠落した。

## 修正
- `load_pdf` で `oxidize-pdf` の画像抽出処理を使い、画像ファイルを一時出力してから base64 化して `ImageElement.data` に格納した。
- JPEG はそのまま、その他の形式は PNG に正規化して保存するようにした。
- 画像抽出が失敗した場合だけ、従来どおりの安全側フォールバックに落とす。

## 再発防止
- `load_pdf` の回帰テストで、生成した PDF を再読込したときに `ImageElement.data` が空でないことを確認する。
- `savePdf` の再生成経路だけでなく、読み込み時点で画像バイトを保持することを前提にする。
