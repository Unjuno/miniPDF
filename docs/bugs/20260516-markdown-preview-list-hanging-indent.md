# Bug Note: Markdown のリスト折り返しインデントが不自然だった

## 症状

Markdown プレビューの箇条書きや番号付きリストで、2 行目以降の折り返しが十分に右へずれず、ネストしたリストの見た目が詰まって見えることがあった。

## Root Cause

リスト項目の続き行を、実座標で右へ移動するのではなく、スペース文字で疑似的に整列していた。そのため、フォント差や折り返し幅の違いで hanging indent が安定しなかった。

## Fix

- リスト項目の 1 行目は bullet / 番号を通常どおり描画する。
- 続き行は prefix 幅から計算した実座標に移動して描画する。
- これにより、ネストしたリストほど明確に右へずれる。

## Regression Prevention

- `list_item_content_x_increases_with_prefix_width` で prefix の幅に応じてコンテンツ開始位置が右へ進むことを確認する。
- 既存の Markdown プレビュー回帰テストと合わせて、リストの見た目崩れを検出する。
