# Markdown HTML プレビュー

miniPDF の Markdown プレビューは、Markdown を HTML に変換してページごとの HTML コンテナとして表示します。
画面上の装飾ではなく、**印刷時のズレ確認**に寄せた紙面再現を目的にしています。

## 使い方

1. 左ペインに Markdown を入力する。
2. 右ペインに HTML ベースのプレビューが自動更新される。
3. 見出し、引用、表、コードブロック、Mermaid の見え方を確認する。

## 制約

- ページ分割は HTML レイアウト用の推定高さを使っているため、PDF 印刷結果と完全一致はしません。
- Mermaid は `mmdc` が利用できると画像化され、画像はページ幅・最大高さの制限付きフレーム内に収まります。`mmdc` が無い場合は短い説明付きプレースホルダに落ちます。
- PDF の保存は従来どおり別経路で動きます。プレビューと保存は同じ Markdown を元にしますが、描画エンジンは分かれています。
- 印刷プレビューでは、`@page` と `break-after` を使ってページ境界を確認します。
